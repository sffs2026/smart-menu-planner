# 外网共享模式

## 行为

- GitHub Pages 独立运行时使用 Supabase 匿名账号；无需手机号、邮箱或公司账号。
- 用户可创建共享菜单，生成 8 位邀请码；朋友输入邀请码后加入同一菜单。
- 菜品、日期、评分、评价和图片按共享菜单隔离，成员可共同新增、编辑和删除。
- 页面每 5 秒静默刷新当前月份，近实时同步朋友的修改。
- 图片缩放至最长边 1400px、压缩为 JPEG 后上传私有 Storage，仅菜单成员可读取。
- 外网 AI 灵感使用内置菜谱规则库，不向第三方 AI 发送食材；公司版仍使用账号存储和服务端 AI。

## 身份与恢复

- Supabase 匿名身份持久化在浏览器中。清除网站数据会失去该匿名身份，需要重新通过邀请码加入。
- 邀请码应只分享给希望加入菜单的人；加入后成员拥有该菜单菜品的增删改权限。

## 验证

- 已使用两个独立匿名账号完成端到端验证：账号 A 创建菜单，账号 B 通过邀请码加入并新增菜品，账号 A 可读取该菜品。
- 测试数据已清理。

## 数据表

- `menus`：共享菜单和邀请码。
- `menu_members`：匿名用户与菜单成员关系。
- `dishes`：菜单下的菜品记录。
- `dish-images`：私有图片存储桶，路径首段为 menu_id。
