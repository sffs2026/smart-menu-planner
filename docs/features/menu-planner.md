# 点菜与饮食日历

## 目标

让用户在一个界面完成「想吃什么 → AI 出菜名菜谱 → 加入某天 → 做完后上传图片和评分」的闭环。

## 核心功能

- 月历：按天展示已安排菜品，可切换月份和选中日期。
- 菜品记录：菜名、类别、日期、原料、菜谱、评分、评价。
- 自定义图片：JPG/PNG/WebP/GIF，单张不超过 5MB。
- AI 灵感：输入类别、现有食材与口味偏好；现有食材仅作为候选，AI 可选择其中几种合理搭配，也可推荐补购新食材；生成结果可一键加入选中日期。
- 弹层兼容：菜品表单在微应用容器内渲染，避免 qiankun 样式隔离导致点击后弹层不可见。
- 分类：预置海鲜、肉类、蔬菜、汤羹，同时允许自定义输入。

## 状态流

AI 生成草稿 → 用户检查/编辑 → 保存为菜品 → 可上传成品图 → 可打分和写评价 → 后续可编辑或删除。

## 边界

- 所有数据按 SSO 用户隔离。
- 图片持久化到 PostgreSQL Large Object，不写临时磁盘。
- 默认显示当前月份；日历筛选只影响列表，不删除其他月份数据。
- AI 返回异常时保留用户输入并允许重试。
